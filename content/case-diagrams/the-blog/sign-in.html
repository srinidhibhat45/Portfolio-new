Signing in to write

Signing in went from a GitHub account to one password on the page

The editor's first version, 27 July 2026

Sign in with GitHub: a GitHub session on the device, or a key pasted in by hand

Later that night: a password, behind a button and a popup

Press "Sign In with GitHub"
→
A popup opens
→
Type the password

Now, from 28 July 2026

Type the password on the page. The editor opens signed in and stays signed in on that browser.

Why the button existed

A browser will not open a popup without a click. Moving the password form into the page removed the need for both.

What guards it

The password is checked on the server, slowly on purpose, with a one-second wait after every wrong try. The GitHub key it unlocks can only change this one repository.
