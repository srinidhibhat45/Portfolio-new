The writing interface, drawn from its settings

One form per post, with a hint under every field

Title

Keep it under about 70 characters.

Summary

One or two sentences. Shown on cards, in search results and when the link is shared.

Publish date

Sets the order and the date in the sitemap.

URL slug

The post lives at /p/slug/. Changing this on a published post breaks every link to it.

Cover image and its description

Saved into the post's own folder. The description is for screen readers.

Topics and tags

Topics come from a list. The first one is shown on the post's card.

Draft on

Saved to the repository but kept off the live site. Turn it off to publish.

Feature this post, and Fact panel

Credits or key facts, such as film details on a review, shown beside the article.

Body

Write, paste or drag images in. A fenced block with no language is rendered as verse: use it for poems.

A drawing of the fields and hints the editor is set up with, not a screenshot of the editor. Save sends the post to the repository.
