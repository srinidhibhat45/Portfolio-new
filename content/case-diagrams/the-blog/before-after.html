A ready-made Hugo theme

  • A new post meant a Markdown file, a terminal and a commit
  • Poems sat in code blocks so their line breaks would survive

My own design, in Astro

  • My own layout and four typefaces, one of them for Devanagari

  • Write and publish from any browser, with a password
  • Poems render as verse
  • Three series pages, each in reading order
  • All 32 posts moved, and every old link still works
