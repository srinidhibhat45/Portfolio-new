How it works

Writing goes in through the browser. Readers get plain pages.

When I write

Any browser

Phone or laptop. Open the editor and type one password.

→

Sign-in function

Checks the password on Netlify and hands back a GitHub key stored there.

→

The editor

Sveltia CMS. A form for each post, with Draft on or off.

→

Save

Each save is a commit to the private repository.

↓

What happens next

Netlify build

Astro turns the posts into static pages.

→

Search index

Pagefind reads the built pages and writes a search index.

→

Live site

The post is up in a minute or two. Drafts are left out.

→

Reader

Static pages. Search runs in the browser. Comments load only when reached.

There is no server or database behind the editor. The repository is the only store.
