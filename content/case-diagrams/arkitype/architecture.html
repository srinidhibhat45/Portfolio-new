How it is put together

One file in the middle, and everything else is compiled from it

In the browser

The design file

Colours, type, spacing, shape, motion, component settings and written pages, held in one store.

↓

Token compiler

Turns the file into CSS variables, for light and dark.

↓

Canvas

90 components that read only those variables, so a change shows without redrawing by hand.

→

Compiled from the file

17 export formats

Each one is generated when it is picked. None is edited by hand.

Published styleguide

A frozen copy at its own link. Edits stay private until it is republished.

Figma plugin

Reads the same bundle and builds or updates a Figma file in place. It is released separately from the web app.

↔

On the server

Supabase (Postgres)

Accounts, saved files, collaboration and published copies.

Rules in the database

Who can read or edit a file, and each plan's limits, are enforced there and not in the browser.

Stripe

Billing. Optional: with no keys set, every account is on the free plan.

The tool's own interface and the design system being built use two separate sets of variables that never mix.
