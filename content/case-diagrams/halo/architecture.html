How it is put together

Two native apps around one shared description of a ring

Mac app · Swift

Core logic, no interface

Slot maths, the tap-or-hold rules, rings and settings. Tested on its own.

↓

The ring window

Floats over every app and every desktop, and never takes focus.

↓

Actions

Keys, media, windows and in-app actions, through Accessibility.

Settings and editor

SwiftUI inside AppKit windows.

↔

Shared

One settings file

Readable JSON in the same shape on both systems. A ring exported on a Mac opens on Windows.

One list of in-app actions

369 actions for 30 apps, with sources and keys for both systems. One script writes the list and the Mac code.

One spec

Behaviour, sizes, colours and motion timings, written down for both.

GitHub Releases

Both apps check once a day and ask before installing.

↔

Windows app · C#

Core logic, no Windows code

Every Mac core test ported, plus more. Runs on any system.

↓

The ring window

Keyboard and mouse hooks on their own thread, so a busy screen never slows typing.

↓

Actions

Windows' own equivalents. Mac-only kinds show as unavailable.

Settings and installer

WPF with the Fluent theme. Velopack for install and updates.

No third-party code on the Mac. Two small packages on Windows: Velopack for updates and one for laptop screen brightness.
