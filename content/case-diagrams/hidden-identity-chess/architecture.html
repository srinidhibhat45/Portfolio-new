How it is put together

One rules file, used by the phone and by the server

On the device

Game screen

Plain JavaScript and CSS, with no framework. Draws the board, sheets and the original piece drawings.

↓

Rules engine

Setup, moves, bluffs, challenges, penalties and the computer player. One file.

↓

Saved on the device

Computer and pass-and-play games save after every move and work offline.

Service worker

Stores all 11 game files for offline play. Install is offered only once every file is saved.

↔

Online rooms only

Rooms API

Imports the same rules engine and checks every move on the server. The browser cannot decide a move is legal.

Seven-character room code

Each seat gets a long secret token. The server stores only a hash of it, never the token.

Revision number

A move sent against an old board is refused, so two moves at once cannot both win.

→

What each player receives

A filtered view

The server turns every enemy piece into "?" before sending the board. Kings show only in games set to revealed kings.

Never sent

The private record of which bluffs were legal stays on the server. A test searches each player's copy of the board for any trace of it.

Cloudflare D1

Stores each room's state. Rooms expire after 48 hours without a move.

Computer and pass-and-play games never talk to the server. Online moves are never queued while offline; the game reconnects and reloads the true board instead.
