How it is put together

Everything that touches the deck runs in the browser tab

In the browser

Extraction

pdf.js reads the file. The rebuilding code turns pages into layers.

The project store

The deck, its layers and the undo history, kept in Zustand.

One renderer

Canvas, slide rail, layer thumbnails and presenter mode all draw through it, so what you edit is what you present.

Animation

Each preset is a function of progress from 0 to 1, so it can be played, scrubbed or sampled.

Exports

Video drawn frame by frame from the layers. One HTML file with the motion baked into CSS and no JavaScript. A project file.

Library

Every deck saved in the browser's own storage on this machine, each at its own link.

When run locally

A small relay on the same port as the app passes messages between laptop and phone.

On the live site

A small function acts as a mailbox. The two devices swap a handshake through it, then talk directly.

If direct traffic is blocked

The mailbox carries slide control and small preview pictures, and keeps them for under a minute.

The PDF itself is never uploaded. A built copy served as plain files works fully except the remote, and says so.
