Three ways to sit down

The setup asks how many devices are in the room

Bots

One person, 1 to 23 bots

Devices
One
Network
Not needed after the first full load
Hidden hands
Each bot sees only its own hand and the total
If you leave
The game is saved in the browser to resume

Pass & play

2 to 24 people

Devices
One, handed round the table
Network
Not needed after the first full load
Hidden hands
A cover screen between turns. Private by trust, not by lock
If you leave
The game is saved in the browser to resume

Online room

2 to 24 people

Devices
One each. The host shares a link or a six-character code
Network
Needed the whole time
Hidden hands
The server sends each player only their own hand
If you leave
The table waits for you to come back

All three use the same rules engine. Only the online room needs the server.
