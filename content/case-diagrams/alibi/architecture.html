How it is put together

The server owns the game. Browsers only show their share of it

In each player's browser

The game screen

React, built with Vite. It draws whatever state the server last sent, and sends actions back.

YouTube player

The official embedded player. It plays only the assigned part of the clip. Nothing is downloaded.

Recent clips

The last 64 video IDs, kept in the browser and shared with the server on joining.

⇄

Socket.IO: actions in, a filtered room state out

On one Node server

Rooms

Held in memory. Players, phase, timers, clues, votes and scores. A restart ends every room.

Game rules

Picks pairs and the imposter, checks every action, moves phases on, tallies votes.

Express

Serves the built app, a health check, the pack list and the call settings.

⇢

Optional

Calls

In-app call

WebRTC: browsers connect to each other directly. The server only passes on the setup messages.

Relay server

Needed only when networks block direct links. Not set up yet.

Teams

The call the group planned to use on game night. It runs outside the app.

Hosting: a Docker file and a Render setup are ready, but no permanent host is running. For a game night, a script can serve the app from my computer through a temporary public link.
