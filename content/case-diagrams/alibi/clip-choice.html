Decision 3, in the build

How the server picks the next pair of clips

1

Start from the chosen pack

The mixed bag: 8 pairsFood for thought: 2Animal instincts: 2Mind blown: 3The throwbacks: 1The host's own: up to 20

The pairs live only on the server, so no one can read them in the browser.

2

Drop pairs already played in this game

If none are left, start the pack again and say so in the room chat.

A small pack has to repeat. The throwbacks pack has one pair. Better to admit it.

3

Drop the pair that was just played

As long as another pair is available, even across a restart of the pack.

Seeing the same clips twice in a row gives the game away.

4

Prefer clips nobody in the room has seen lately

Each browser keeps its last 64 video IDs and shares them with the server, never with other players.

Players who have played before should get new clips in a new room.

5

Pick at random from what is left

Then decide at random which clip is the odd one, and who gets it.

The host chooses the pack but cannot know the imposter.
