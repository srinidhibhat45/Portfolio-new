How a new version reaches the phone

Every update is checked twice: before it is published, and before it is installed

On GitHub, after each change

Tests and lint

The unit tests and Android's code checks run first. A failure publishes nothing.

Optimised build

The phone app and the watch app are built for release.

Signed

With Forma's own signing key, held as an encrypted secret and deleted after use.

Published

The app, a small manifest and a checksum, under a new build number.

↓

On the phone

Finds it

Checks at most every 15 minutes while open, and every six hours in the background.

You tap update

Nothing downloads on its own.

Forma checks the file

Size, checksum, package name, a higher version number and the same signing key. Any mismatch stops it.

Android asks you

The system installer replaces the app in place. Records and targets stay.

Android always asks before installing, so an update can never replace the app silently.
