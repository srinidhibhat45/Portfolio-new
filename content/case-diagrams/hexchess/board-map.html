The board

91 cells, 11 files and three shades

Files run up the board

Eleven files, a to l. The letter j is skipped, as in Gliński's original. f, in the middle, is the longest at 11 cells.

A name counts up from White's end

f6 is file f, cell 6: the centre, outlined here. The names stay the same when the board is flipped.

Three shades, not two

No two cells that share an edge have the same shade. Each side has three bishops, one for each shade.

Drawn from the same formula the game uses to lay out and name its cells, in the shades of the default Classic board.
