How it is put together

Everything runs in the browser. The server only hands out files

What you see

React interface

The board drawn as SVG, the lessons, the rules guide, dialogs and the move list.

↓ every tap

One legal-move gate

Your moves, the computer's replies, premoves and moves arriving in a link all pass the same check.

→

The game

Rules engine

91 cells from hex coordinates, every piece's moves, check, en passant, promotion and the draw rules.

Session

A game is its settings and its list of moves. The board is rebuilt by replaying them.

Computer opponent

Searches in a Web Worker, a background thread, so the board never freezes while it thinks.

→

Kept on the device

Local storage

Autosave, preferences and a queued premove. Nothing goes to a server.

Game links and files

The move list, encoded into a link or exported as a file.

Service worker

Saves the whole app after the first visit, so it plays offline. Updates wait until open tabs close.

Hosted as static files on Vercel. No accounts, database, analytics or live connection.
