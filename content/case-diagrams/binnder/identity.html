Why a stale decision cannot hit the wrong file

A file is five facts, not a name

Path

Where it lives

Size

In bytes

Modified time

Last change

Device

Which storage volume

Inode

The number the file system gives that exact file

An example of what this prevents

1. You bin a file

Size8.2 MB
Inode40211

2. Within five seconds, another app saves a new report.pdf in the same place

Pathsame

3. The move is cancelled

The facts no longer match, so the new file is never touched. You see: "report.pdf changed or moved; deletion cancelled."

The file name, sizes and numbers are an illustration. The five facts and the message come from the app's code. The same check makes a kept file come back for review if it changes.
