How it is put together

Everything runs on the phone. Only updates use the internet

On screen

Review, Recycle bin, Settings

Jetpack Compose and Material 3. Follows the phone's light or dark theme and wallpaper colours.

Previews

Images and every PDF page with pinch zoom, video, audio and text. The next files are drawn ahead, in a 24 MB memory cache.

Swipe and buttons

One drag handler, three buttons and three named screen-reader actions, all calling the same functions.

→

The app's logic

Review queue

Largest first, filtered by kind. Holds the waiting actions and drives each countdown.

Rules

Five seconds to undo, seven days for a kept file, thirty days in the bin. What counts as someone else's bin.

→

On the phone's storage

Storage

Scans each volume, records each file's five facts, keeps the history of kept files and the record of every action in SQLite.

Safe disk

Moves a file only if it is unchanged and nothing is at the destination. Deletes one file, never a folder.

A hidden bin folder

One on each volume, so a move to the bin never copies the file.

↔

In the background

Hourly cleanup

WorkManager finishes waiting actions and empties expired bin files, when Android allows.

Update check

Reads public GitHub releases. Checks the file's SHA-256, package name, a higher version and the exact signing certificate before offering to install.

No accounts, no analytics, no uploads. The update check is the only part that uses the network.
