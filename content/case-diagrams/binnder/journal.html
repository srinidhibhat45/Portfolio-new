If the app is killed half way

On the next run each record is checked against the disk. A file found in the bin is marked as binned. A file still in its old place is left alone. Anything that does not add up is kept and reported, never guessed.

If a step fails

A failed move leaves the original where it was. A failed restore leaves the file in the bin. A failed delete keeps the file. Folders are never deleted, only single files.

Drawn from the app's storage code. The records live in a small SQLite database on the phone. Restoring goes back through its own "restoring" step, not shown.
