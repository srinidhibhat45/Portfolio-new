What each tool did well, and where it fell short

SEO META in 1 CLICK

4 strengths4 weaknesses

Strengths

  • A vast amount of SEO data
  • Simple, to-the-point interface
  • Easy to navigate
  • Useful tooltips for every feature

Weaknesses

  • Simple, but looks outdated and uninviting
  • The data could be organised better
  • Not beginner friendly. Takes time to get used to
  • Cannot export the data

All in One SEO Analyzer

6 strengths1 weakness

Strengths

  • Visually appealing
  • Information is organised very well
  • A vast amount of SEO data
  • Easy to use
  • Beginner friendly
  • Useful tooltips for every feature

Weaknesses

  • Data runs down the panel in one long column. A large website would be a pain to go through

Detailed SEO Extension

9 strengths2 weaknesses

Strengths

  • Modern and visually appealing
  • Information is organised very well
  • A vast amount of SEO data
  • Its own right-click menu, anywhere on the web
  • Easy to use
  • Beginner friendly
  • Useful tooltips for every feature
  • Advanced options
  • Dark mode

Weaknesses

  • Data runs down the panel in one long column. A large website would be a pain to go through
  • Copy has replaced export

getMetaData
the tool I was redesigning

4 strengths4 weaknesses

Strengths

  • The only one that shows every metric at one time
  • A vast amount of metrics, though fewer than the others
  • Metrics are easy to export
  • To-the-point interface

Weaknesses

  • The interface is outdated
  • A bug: every time the extension opens, the data is shown twice
  • Very small text. Hard to read and understand
  • Poor organisation of information
