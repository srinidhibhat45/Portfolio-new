How it is put together

Music maths at the bottom, the screens on top, nothing leaves the phone

Pure music

Music theory and detection maths

Notes, chords, chord shapes, the five gates, matching a step, reading chords out of a score. No React and no audio, so all of it can be tested on its own.

→

Sound in and out

One listener, two inputs

Microphone and USB MIDI merged into one “what is sounding now” signal.

Basic Pitch model

Loaded the first time you press Listen. Weights ship with the app.

Practice synth

A simple piano voice for Hear it and the metronome.

→

Screens and storage

Six screens

Library, Play, Zen, Progress, Editor and Settings, drawn with my own small set of controls.

On-device storage

Your songs, progress and rewards, kept in separate stores in the browser's storage.

→

Where it runs

Android app

The same web build inside a thin Capacitor shell.

Any browser

A laptop propped on the piano is a real use.

Live updates

Each push runs the types and tests, then publishes a new web bundle that installed apps pick up.

Lower layers never import upper ones. The only network request is the Android app asking whether a newer bundle exists, and it sends nothing about you.
