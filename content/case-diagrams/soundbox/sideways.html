One button, three ways to turn sideways

Tried in order, so the button works even with auto-rotate off

1

Ask the Android app

The thin Android shell tells the system to rotate. Auto-rotate does not get a vote.

Built and compiled. Not yet watched on a device.

→
2

Ask the browser

Lock the screen to landscape. Browsers allow it only in full screen, so it is tried only on an upright touchscreen.

Checked in the browser.

→
3

Turn the page itself

Rotate the whole page 90 degrees. It cannot fail, and it is the route most phones will take.

Checked in the browser.

Live updates replace the web code without a new Android install, so an older app can be running newer code. That is why route 3 had to exist.
