How a message travels

Four ways in, one path through, three ways out

Ways in

Inbox scan

Reads up to a year back on first run, then anything since the last scan.

Live listener

Catches an alert as it arrives while the app is open.

Background capture

Runs when the app is closed, with its own database connection.

Share to PreMoney

Send a message from another app through its share menu.

Parser

Categoriser

Where it ends up

Saved once

Each entry gets a key made from the message itself. The database refuses a second copy, so the four routes can overlap safely.

Review queue

Saved, but flagged when the category is a guess or the merchant could not be named.

Not saved

OTPs, adverts, statements, failed payments, requests. The reason can be checked in the message tester.
