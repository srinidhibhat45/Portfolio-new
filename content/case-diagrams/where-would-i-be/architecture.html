How it is put together

Data built once, then every plate moved on the graphics card

Built once, before deploy

Open data

Plate motions (NNR-MORVEL56), plate outlines (PB2002), coastlines and borders (Natural Earth), place names (GeoNames).

↓

A build script

Cleans them into four JSON files, works out every boundary's type, and checks the plates add up to 510.1 million km².

→

In the browser, at load

Plate maths

Each plate is a cap turning about its own pole. A point's whole future is one rotation.

↓

The mesh

Land and plates cut into triangles. Every corner is tagged with the plate it belongs to.

→

Every frame

52 rotations, one small texture

The rotation of each plate is packed into a 64 by 1 texture and sent to the graphics card.

↓

A shader moves each corner

Each corner is turned by its own plate. Lines are thin strips of triangles, so they ride the crust too.

No server and no analytics. A shared location is used in the browser and never sent anywhere.
