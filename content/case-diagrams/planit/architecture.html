How it is put together

Everything runs in the browser, and the network is optional

On screen

Eight views and a details panel

Timeline, Day, Trip, Agenda, Map, Canvas, People, Ideas. Each one can add, move and remove blocks.

↓

One store

Every change goes through one place, which keeps undo and redo and saves the trip.

↓

The core: no screens in it

Time zones, the travel model, the analyser, the board and Resolve, sub-trips, sharing and calendar files. Tested on its own.

→

Kept or handed out

Browser storage

One saved entry per trip, plus a small index. If the index breaks, it is rebuilt from the trips.

Share link

The whole plan, compressed into the part of the link after the #, which browsers never send to a server.

Calendar file, JSON backup, print

Calendar times written in UTC, so each calendar app shows them in the reader's own zone.

↔

Online, if available

Road routes

From a public routing service. Without it: a straight-line estimate.

Map tiles

From OpenStreetMap. Without them: a blank map with the stops still drawn.

Place search

Live results join a built-in list of places that answers on the first keystroke.

No server, no account, no database. What leaves the browser is search terms and coordinates for those three lookups.
