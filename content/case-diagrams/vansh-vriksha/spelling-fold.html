After folding, search still allows up to two letters of difference, and those near misses rank below a matching key.

The folding rules, in order

  1. Letter pairs first: sh→s, bh→b, th→t, ksh→ks and others
  2. Drop a stray h, except at the start of a name
  3. Same sound, one letter: w→v, f→p, x→ks
  4. Long vowels: aa→a, ee→i, oo→u
  5. y→i, since it works as a vowel in these names
  6. Drop a final a on names of five letters or more
  7. Collapse doubled letters

Keys worked out by hand from the folding code. The order matters: pairs must be resolved before a bare h is dropped. Names written in Devanagari or Kannada script are indexed as they are.
