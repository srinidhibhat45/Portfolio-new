How it is put together

One Next.js app on Netlify, and only the server talks to the database

In the browser

Public pages

Read fresh from the database on each visit, so an edit in the admin shows at once with no rebuild.

Admin portal

Signed in with a cookie the browser cannot read from scripts. Can be added to a phone's home screen.

Print pages

Desk sheet and reports, laid out for paper and kept out of search engines.

→

On Netlify

Next.js server

Every private request checks the sign-in. Private responses are never cached.

Checks and limits

Deadlines in Goa time, duplicate phones, places left, file types and sizes.

Image handling

Uploads are re-encoded with sharp before they are stored.

↔

Services

Supabase, Mumbai

Postgres for events, registrations, ledger and applications. Storage for photos, with a private bucket for applicants.

Groq

A language model drafts press releases and reports from the event's own records.

Netlify Forms and GitHub Actions

The contact form, and a scheduled ping so the free database is not paused for low activity.

Everything runs on the organisation's own accounts. The free plans can still pause, which shaped several choices.
