How it is put together

One document, drawn by the browser, measured back

The document

One store

Every part has the same shape, so undo, copy and paste, and export are each written once. Built with Zustand and Immer.

↓

Every change goes through one door

A whole drag counts as one undo step, and undo never moves your view.

→

On screen

Renderer

Turns each part into page elements. Each part redraws only when it changes.

↓

The browser lays it out

Auto layout is real CSS flexbox and grid.

↓

Measure the live page

Selection, snapping, hit-testing and export read where things really are.

→

Out and away

Browser database

One table of folders and designs. Saves are queued and confirmed.

Images and review page

PNG, SVG, a ZIP of every screen, or a clickable HTML page.

Code

React, HTML or a written spec, from the same document.

Five runtime libraries in all. The canvas, snapping, icons, charts, export, code generation and the ZIP writer are written in the project.
