How it is put together

Three places, one web page, no server for your work

1

Front page

Says what the tool is for. Its examples are drawn by the real renderer, not pasted screenshots, so they cannot go out of date.

→
2

Drive

Folders, designs, starred and trash. Each card is a live thumbnail of the real document.

→
3

Editor

The canvas, the 250-part library, prototype links, comments, versions and export.

Underneath all three

Saved in your browser

Designs live in the browser's own database. No account and no upload.

A file you own

Any design saves to a plain .cider.json file you can keep, send or open again.

Any static host

Addresses use the part after the #, so the page works from any plain web host.
