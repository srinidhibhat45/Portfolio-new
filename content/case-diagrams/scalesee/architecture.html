How it is put together

One small state, eleven drawing functions, no server

What it knows

Categories

11 categories, each with its units, ready-made pairs and a list of real things to compare with.

Numbers behind it

125 reference points, 46 ready-made pairs, 5 currencies at fixed rough rates.

→

What you chose

The state

Category, two sides (number, unit, currency) and the scale mode. Every value is turned into one base unit first.

The address

The state is written into the link after every change, so a link reopens the same comparison.

→

What you see

The sentence

The ratio, plus a borrowed pair of real things.

The drawing

One function per category returns a picture on a fixed 1000 × 560 canvas, plus a note.

Table and references

The same two amounts in other terms, and the list of real things.

A shared drawing kit

Solids, silhouettes and landmarks, lit from one side. The light and dark palettes live here too.

Delivery

Plain files that open from disk, or one self-contained file made by a short build script.
