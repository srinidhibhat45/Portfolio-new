How it is put together

Everything lives on the phone first

Screens

Four tabs and a title page

File-based routes with Expo Router. The same code runs on Android and the web.

↓

Material 3 parts

Buttons, chips, fields, sheets and navigation, all reading one set of colour, type and spacing tokens.

→

On the phone

Library in SQLite

Logs, ratings, bookmarks, diary, collections and episode progress. Backups and restores run from here.

Recommendation engine

Runs on the phone and keeps each feed until the library changes.

Reminders and keys

Local notifications for releases. API keys kept in the phone's secure storage.

↔

Outside the phone

TMDB

The film and series database. Each person adds their own key.

Firebase, optional

Email sign-in and a cloud copy of the library, for a second device.

Gemini, optional

Re-ranks the feed and powers mood picks, only with a key.

EAS Build and Update

Builds the Android app and sends small updates to installed copies.

Dashed boxes are optional. With neither, the app still works fully on one device.
